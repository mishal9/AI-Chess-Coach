# Experiment: Qwen3-8B QLoRA on the v2 mixed-granularity dataset

**Date:** 2026-08-10 · **Status:** complete · **Verdict: grounding gate met (0.91 ≥ 0.85); factual gate missed (3.72 < 4.0)**

Second fine-tuning iteration. Training the same Qwen3-8B QLoRA recipe on a dataset that
mixes whole-game rows with per-critical-position rows raised strict grounding from 0.79 to
**0.91** and lifted every judged axis, without the whole-game regression that mixing risked.
The hypothesis behind v2 — that citation drift is a property of the *training row shape*,
not of insufficient data — is supported.

---

## 1 · Hypothesis

The v1 experiment ([2026-08-08](./2026-08-08-qwen3-8b-qlora-v1.md)) fixed the motivating
hallucination (inventing mistakes in clean games) but introduced a milder failure: the
fine-tune wrote richer coaching that cited *illustrative* moves absent from the facts block,
so strict grounding fell 0.81 → 0.79 even as judged factual accuracy rose 2.90 → 3.45.

Every v1 training row was a whole-game example. Whole-game examples are long and license
discursive, multi-move commentary — a format that invites elaboration. **Hypothesis:** adding
short, single-position rows, whose facts block names only two moves (played and preferred),
drills citation discipline in a format with nowhere to wander, while retaining whole-game rows
so the deployed task (full-game review) is still demonstrated.

**Rejected alternative:** simply distilling more whole-game rows. v1's gold rows were already
100% grounded by construction, so the model saw only compliant examples and drifted anyway —
evidence that volume of the same shape addresses factual coverage, not citation discipline.

## 2 · Data

Built with the PR #28–#31 machinery; full composition in `training/datasets/v2/manifest.json`.

| Source | Rows | Notes |
|---|---|---|
| v1 game rows, **reused** | 104 | Teacher model, teacher system prompt, and facts builder byte-unchanged since v1, so regeneration would only re-sample the same distribution |
| v1 gate-failures, **retried** | 25 of 29 | 86% recovered to grounding 1.0 via `--retries` — rows v1 discarded |
| Position rows | 274 of 330 | 127/137 corpus games, up to 4 worst mistakes each |
| **Total after strict gate** | **403** | 129 game + 274 position |

Splits (leakage-safe per-game SHA-256, seed 0): **train 319 / val 34 / test 50** — 3.9× v1's 82.

**Gate rates diverge by row kind and validate the design:** game rows pass the strict 1.0
grounding gate at 94% (mean 0.988), position rows at 83% (mean 0.938). The tighter facts block
catches teacher drift that the whole-game block tolerates.

Row-kind ratio in training is ≈1 game : 2.1 position. This ratio, not the reuse decision, was
the design risk (see Threats).

## 3 · Training setup

Identical to v1 except the dataset and the GPU, so the comparison isolates data shape:

| Component | Value |
|---|---|
| Base model | `Qwen/Qwen3-8B`, non-thinking mode |
| Method | QLoRA: NF4 4-bit base + LoRA r=16, α=32, dropout=0.05, all 7 linear modules |
| SFT | TRL `SFTTrainer`, 3 epochs, effective batch 16, lr 1e-4 cosine, max_len 2048, seed 0 |
| Hardware | RunPod **RTX 4090** 24GB (EU-RO-1), <30 min wall clock, ≈**$0.40** |
| Export | merge fp16 → GGUF q4_k_m (5.03 GB) → Ollama `qwen-coach-8b-v2` |
| Receipt | `manifest_8b_v2.json` recorded `dataset: "v2 (319 train / 34 val)"`, confirming the intended splits reached the GPU |

GPU note: v1 ran on an A5000. Datacenter capacity forced the change: at run time, the only
datacenters with A5000/A40/A6000 stock (EU-SE-1, CA-MTL-1) **do not support network volumes**,
and RTX 4090 in EU-RO-1 was the sole overlap of GPU availability and volume support. The 4090
finished in roughly half the A5000's wall clock despite a higher hourly rate.

### Findings

1. **The row-shape hypothesis holds.** Grounding rose +0.12 and the share of perfectly
   grounded games rose 20.7 points, reversing v1's regression and clearing the gate. Gains are
   broad, not bucket-specific: five of six buckets improved on grounding.
2. **No whole-game regression.** The pre-registered risk of a 1:2.1 mixed dataset was that
   position-heavy training would degrade full-game structure, showing up as falling clarity and
   actionability. Both *rose* (+0.28, +0.10). Keeping 129 whole-game rows was sufficient to
   preserve the deployed task's format.
3. **clean_draw reaches perfect grounding (1.00).** The bucket that motivated the entire
   project — where the prompted baseline scored 0.38 and invented mistakes in mistake-free
   games — is now fully grounded. Its factual score dipped 0.25 on n=4 (within noise for a
   four-game bucket) while overall stayed flat.
4. **The remaining factual gap is concentrated, not diffuse.** one_blunder (3.20) and
   inaccuracies (3.40) hold the mean down; four buckets are at 3.80–4.25. inaccuracies also has
   the lowest grounding (0.84), making it the natural target for iteration 3.
5. **Retrying gate-failures is cheap and effective.** 86% of previously discarded teacher rows
   were recovered by re-rolling a nondeterministic teacher — 25 training rows for ~$0.60.

## 5 · Threats to validity

Everything in the [v1 record's threats section](./2026-08-08-qwen3-8b-qlora-v1.md#7--threats-to-validity)
still applies (judge–teacher circularity, n=29, single seed, quantized student). New or changed:

- **Confounded GPU change.** v1 trained on an A5000, v2 on an RTX 4090. Both ran identical
  hyperparameters and seed, and QLoRA training is not expected to be hardware-sensitive beyond
  numerics, but the runs are not bit-identical environments.
- **Reused teacher rows.** 104 of 403 rows were generated in the v1 distillation run rather than
  freshly sampled. Teacher model, prompt, and facts builder were byte-identical, so this is
  a reuse of an equivalent sample rather than a different distribution, but it does mean v1
  and v2 share training data, which slightly correlates the two results.
- **Position rows are not independently validated.** Their gate pass rate (83%) is measured
  against the same grounding metric the experiment reports, so both the training filter and the
  headline metric share a definition of "grounded." A judge-based or engine-verified citation
  check would break that shared dependency.
- **clean_draw n=4.** Its factual dip (−0.25) rests on four games; do not read it as a signal.

## 7 · Next

- **Close the factual gap (3.72 → 4.0)** by targeting one_blunder and inaccuracies rather than
  scaling the dataset uniformly — those two buckets hold the mean down.
- **Free ablation, no teacher calls:** retrain on `kind`-filtered subsets (game-only,
  position-only) to attribute the gain between data *volume* and data *shape*. The mixed result
  alone cannot separate them.
- **`eval.run --resume`.** This run was lost once at game 24 of 29 because the report is only
  written at the end; the wasted judge calls cost ~$0.40. Incremental writes would make a killed
  run resumable, mirroring `training.distill --retries`.
- Before publication, run the [one-time protocol](./paper-protocol.md): 3 seeds, Wilcoxon on the
  paired design, a second judge, and the scale-vs-fine-tune ablation.

## Operational notes

- Anthropic credits, not GPU time, are this project's binding constraint: the full v2
  distillation exhausted the account mid-run (workers exited cleanly; no corruption), and each
  29-game judged eval costs ~$0.50 against ~$0.40 for an entire training run.
- macOS memory pressure (5 GB model + Stockfish on 16 GB) is a real risk during eval; the first
  attempt was killed at game 24. Running the eval detached (`nohup`) survived.
